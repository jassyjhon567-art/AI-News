কীভাবে Google একটি Linux কার্নেল TCP বাগের ক্ষেত্রে GKE API টাইমআউট ট্র্যাক করেছে

www.infoq.com · Sat, 21 Nov 2026 09:44:00 GMT

Google সম্প্রতি বিশদভাবে জানিয়েছে যে কীভাবে Google Kubernetes Engine (GKE), Private Service Connect এবং Linux কার্নেল জুড়ে তিনটি ইন্টারঅ্যাক্টিং বাগ বিরতিহীন Kubernetes API-এর কারণ হয়েছিল...

Google সম্প্রতি বিশদভাবে জানিয়েছে যে কীভাবে Google Kubernetes Engine (GKE), Private Service Connect এবং Linux কার্নেলের মধ্যে তিনটি ইন্টারঅ্যাক্টিং বাগ বিরতিহীন Kubernetes API সংযোগ ব্যর্থতার কারণ হয়েছিল, যার ফলে প্রায় ৮০০ ডেভেলপার প্রোডাকশনে ডিপ্লয় করতে পারেননি। রেনা্টো লসিয়ো দ্বারা

এই প্রতিবেদনে "গুগল কীভাবে GKE API টাইমআউটগুলিকে একটি লিনাক্স কার্নেল TCP বাগের সাথে সম্পর্কিত করেছিল" এর সাথে সম্পর্কিত মূল অগ্রগতিগুলিকে হাইলাইট করা হয়েছে, যা এই গল্পটি যেভাবে উন্মোচিত হতে চলেছে তার বৃহত্তর প্রভাবগুলি বুঝতে চান এমন পাঠকদের জন্য প্রাসঙ্গিকতা প্রদান করে।

সরাসরি উদ্ধৃতি এবং অতিরিক্ত প্রসঙ্গ সহ সম্পূর্ণ বিবরণ সম্পর্কে আগ্রহী পাঠকদের এই নিবন্ধের শেষে লিঙ্ক করা মূল উৎসটি দেখতে পরামর্শ দেওয়া হচ্ছে।
