অ্যানথ্রপিক GitHub পুল রিকোয়েস্ট রিভিউ এবং ফিক্সের জন্য ক্লড শিপ চালু করেছে

www.marktechpost.com · Tue, 24 Nov 2026 00:02:39 +0000

Anthropic-এর Claude Ship-এ Code Review, PR Steward এবং Claude Approvals-এর বান্ডেল রয়েছে যা GitHub-এর পুল রিকোয়েস্ট পর্যালোচনা, সংশোধন এবং অনুমোদন করে। কোড রিভিউ GA; বাকি ২টি এজেন্ট পাবলিক...

Anthropic-এর Claude Ship-এ Code Review, PR Steward এবং Claude Approvals-কে একসঙ্গে যুক্ত করা হয়েছে যাতে GitHub-এর পুল রিকোয়েস্টগুলি পর্যালোচনা, সংশোধন এবং অনুমোদন করা যায়। কোড রিভিউ GA-তে রয়েছে; অন্য 2টি এজেন্ট টিম এবং এন্টারপ্রাইজের জন্য পাবলিক বিটা-তে রয়েছে। GitHub পুল রিকোয়েস্ট পর্যালোচনা এবং ফিক্সের জন্য অ্যানথ্রপিক ক্লড শিপ চালু করেছে এমন পোস্টটি প্রথমে MarkTechPost -এ প্রকাশিত হয়েছিল।

এই প্রতিবেদনটি "GitHub পুল রিকোয়েস্ট রিভিউ এবং ফিক্সের জন্য অ্যানথ্রপিক ক্লড শিপ লঞ্চ করেছে" এর সাথে সম্পর্কিত মূল অগ্রগতিগুলিকে হাইলাইট করে, এই গল্পটি যেভাবে উন্মোচিত হতে থাকে তার বৃহত্তর প্রভাবগুলি বুঝতে চান এমন পাঠকদের জন্য প্রেক্ষাপট প্রদান করে।

সরাসরি উদ্ধৃতি এবং অতিরিক্ত প্রসঙ্গ সহ সম্পূর্ণ বিবরণ সম্পর্কে আগ্রহী পাঠকদের এই নিবন্ধের শেষে লিঙ্ক করা মূল উৎসটি দেখতে পরামর্শ দেওয়া হচ্ছে।
