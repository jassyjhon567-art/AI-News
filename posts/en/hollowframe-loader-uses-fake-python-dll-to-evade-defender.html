New HollowFrame Loader Conceals Malicious Go Code in Fake Python DLL to Bypass Windows Defender

www.infosecurity-magazine.com · Mon, 03 Aug 2026 11:26:00 GMT

The newly discovered HollowFrame loader hides malicious Go code within a spoofed Python DLL after setting up Microsoft Defender exclusions to bypass security detection.

Security researchers have uncovered a new stealthy malware loader dubbed "HollowFrame," which conceals malicious code written in Go inside a spoofed Python Dynamic Link Library (DLL). Designed primarily to bypass endpoint security controls, the loader exploits trusted application structures to evade detection by security tools such as Microsoft Defender. This tactic highlights an escalating trend among cybercriminals who leverage legitimate runtime components to disguise malicious activities on targeted systems.

A critical aspect of the HollowFrame attack sequence involves pre-staging system exclusions prior to payload execution. By manipulating system settings to establish Defender exclusion paths, the operators ensure that the fake Python DLL can run without raising immediate security flags. Once these exclusions are active, the loader securely drops and executes the Go-based malware, allowing it to establish persistence and perform secondary actions on the compromised machine without triggering real-time threat prevention mechanisms.

Cybersecurity experts warn that using masqueraded DLLs alongside pre-configured exclusion rules presents a significant challenge for traditional security monitoring. To combat threats like HollowFrame, organizations are urged to implement strict administrative controls, regularly audit security tool exclusion lists, and deploy behavior-based detection mechanisms capable of identifying unauthorized configuration changes. Enhanced vigilance and proactive threat hunting remain vital in detecting such sophisticated evasion techniques before significant damage occurs.
