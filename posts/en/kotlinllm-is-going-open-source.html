KotlinLLM Goes Open Source: A New Prototype for Integrating AI into Kotlin Applications

blog.jetbrains.com · Tue, 28 Jul 2026 07:50:41 +0000

KotlinLLM has been released as an open-source research prototype, enabling developers to delegate runtime logic to LLMs by dynamically generating and updating Kotlin source code.

Developers and AI researchers have officially made KotlinLLM public as an open-source research prototype. The new framework is designed to seamlessly delegate runtime application logic directly to Large Language Models (LLMs) from within native Kotlin code. By releasing the codebase to the public, the creators aim to provide software engineers with a more integrated, efficient method for leveraging cutting-edge artificial intelligence capabilities within their existing software architectures without introducing unnecessary system overhead.

Unlike traditional AI integration methods that require making explicit API calls to an LLM on every user request or operating a separate autonomous agent, KotlinLLM introduces a novel architectural mechanism. Developers can define explicit Kotlin calls where the actual function body consists of dynamically generated Kotlin source code. This synthesized code executes natively inside the application environment and can automatically update and refine itself as the application runs and encounters new runtime conditions.

By transitioning KotlinLLM into an open-source project, the research team hopes to foster greater community collaboration, gather critical feedback, and further push the boundaries of automated program synthesis. The project represents a promising step toward embedding dynamic AI-driven logic into statically typed programming languages. Ultimately, it bridges the gap between traditional software engineering practices and the rapidly evolving landscape of modern artificial intelligence workflows.
