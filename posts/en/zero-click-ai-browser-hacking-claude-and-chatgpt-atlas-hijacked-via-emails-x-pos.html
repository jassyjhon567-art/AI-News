Zero-Click AI Attacks Expose Claude and ChatGPT Atlas Browser Extensions to Hijack Risks

www.securityweek.com · Thu, 06 Aug 2026 12:54:09 +0000

Cybersecurity researchers from Zenity have revealed unpatched zero-click vulnerabilities in AI tools like Claude and ChatGPT Atlas, which allow attackers to hijack browser extensions via malicious emails and social media posts.

Cybersecurity researchers from the security firm Zenity have uncovered critical vulnerabilities in leading artificial intelligence platforms, demonstrating that sophisticated AI browser extensions and agents can be covertly hijacked without requiring any user interaction. The findings highlight zero-click exploit vectors targeting advanced tools like Anthropic's Claude and OpenAI's ChatGPT Atlas extensions. By utilizing indirect prompt injection techniques, malicious actors can compromise an AI system's operational integrity simply by delivering specially crafted data through everyday communication channels, including incoming emails and public social media posts on platforms like X.

The attack mechanism relies on hiding malicious instructions within benign-looking digital content that an AI agent is designed to automatically read, summarize, or process on behalf of the user. When the AI tool encounters this compromised text during routine browsing or task execution, it unwittingly interprets the hidden prompt as a legitimate command from the user. Consequently, attackers can manipulate the browser extension to extract confidential user data, perform unauthorized actions across open web applications, or silently exfiltrate sensitive personal information without raising immediate suspicion.

Zenity researchers officially disclosed these severe security flaws to both Anthropic and OpenAI in late 2025 and early 2026, providing technical details to assist in remediation. Despite these responsible disclosures, reports indicate that the vulnerabilities currently remain unpatched, leaving users potentially exposed to ongoing automated exploits. As browser-integrated AI capabilities continue to expand rapidly across consumer and enterprise environments, cybersecurity experts stress the urgent necessity for developers to implement stronger input validation and contextual boundaries to mitigate prompt injection risks.
