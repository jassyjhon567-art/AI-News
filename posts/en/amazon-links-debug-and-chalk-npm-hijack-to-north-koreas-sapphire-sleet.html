Amazon Attributes Major Npm Supply Chain Attack to North Korean Hackers

thehackernews.com · Thu, 30 Jul 2026 11:35:17 +0530

Amazon has attributed a major npm supply chain attack affecting billions of downloads to the North Korean threat group Sapphire Sleet following a ten-month investigation.

Cybersecurity researchers at Amazon have formally attributed a high-profile open-source supply chain attack involving popular npm packages, including debug and chalk, to Sapphire Sleet, a well-known North Korean state-sponsored threat group. The compromise affected fundamental JavaScript libraries that serve as essential building blocks for millions of web applications and digital platforms across the globe. By establishing this explicit connection to a cyber espionage and financial crime unit, security experts have emphasized the rising vulnerability of open-source software registries to sophisticated state-backed operations.

The mechanics of the breach involved a sophisticated phishing campaign directed at a primary package maintainer through a deceptive lookalike domain designed to mimic the official npm portal. Upon gaining unauthorized access, the threat actors successfully deployed a wallet-draining script across at least 18 separate software packages. Given that these targeted libraries collectively generate more than two billion weekly downloads, the malicious code posed a widespread risk to developer workstations, enterprise environments, and downstream software deployments worldwide.

Following the initial breach, the incident sat in public cybersecurity records for nearly ten months as a standard cryptocurrency theft operation. Initial analysis conducted by security firms such as Aikido and Wiz provided critical technical details about the malicious script but lacked definitive state-level attribution. Amazon’s latest intelligence report fills this gap, illustrating how state-sponsored cyber units are systematically exploiting trusted software dependencies to execute covert operations and harvest financial assets on a massive scale.
