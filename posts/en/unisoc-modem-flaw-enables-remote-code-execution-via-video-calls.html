Critical UNISOC Modem Vulnerability Allows Remote Code Execution Through Video Calls

www.infosecurity-magazine.com · Mon, 17 Aug 2026 15:45:00 GMT

A critical vulnerability in UNISOC smartphone modems allows remote attackers to gain kernel-level code execution simply by initiating video calls to target devices.

Cybersecurity researchers have uncovered a severe security vulnerability affecting UNISOC baseband modems, which are widely deployed across millions of budget and mid-range mobile devices worldwide. The critical flaw enables remote threat actors to achieve kernel-level code execution on affected devices without requiring extensive user interaction or physical access, raising substantial alarms regarding user privacy and system integrity.

According to security analyses, the vulnerability is triggered through standard cellular video calling protocols. By sending specially crafted network packets during an incoming video stream, an attacker can manipulate the way the baseband processor handles multimedia data. Once processed by the modem firmware, the memory corruption flaw is exploited to escape conventional restrictions and gain low-level execution rights directly in the device's kernel environment.

Baseband modem vulnerabilities are considered especially dangerous because they operate beneath standard operating system defenses and application sandboxes, making detection and containment difficult for typical mobile security tools. Industry specialists urge hardware manufacturers and mobile network operators to release and distribute corrective firmware patches immediately. In the meantime, smartphone users are strongly advised to install the latest security updates to protect against potential exploitation.
